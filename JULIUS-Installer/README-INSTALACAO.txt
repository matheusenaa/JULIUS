JULIUS - Executável Windows (PyInstaller)

Como instalar:
1. Copie a pasta JULIUS/ para C:\Program Files\JULIUS (ou qualquer local)
2. Crie um atalho para JULIUS.exe (Desktop/Menu Iniciar)
3. Execute JULIUS.exe - abre em janela própria (modo app) ou navegador
4. Dados: %LOCALAPPDATA%\JULIUS\ (banco, arquivos, logs, chave secreta)
5. IA opcional: %LOCALAPPDATA%\JULIUS\julius.env

Não requer Node.js, Python, Rust, Git instalados.
